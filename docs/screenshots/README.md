# Screenshots

Generated by `make screenshots` (`node scripts/screenshots.mjs`) from the real
demo backend (`python3 -m omniwatch serve --demo --demo-clock 1790000000
--demo-seed 7`, temporary config dir), in headless Chromium at 1440×900 @2x with
`reducedMotion: 'reduce'`, locale `en-US`, timezone `America/New_York` and the
page clock pinned to the demo clock. Reruns are byte-identical;
`node scripts/screenshots.mjs --verify` re-renders into a temp dir and compares.

Naming: `<name>-<theme>.png`, `theme` ∈ `dark`, `light`. Names referenced from
`README.md` and `docs/USER_GUIDE.md`: `split`, `list`, `grid`, `zoom`, `usage`,
`palette`, `quick-reply`, `onboarding`, `projects`, `empty-not-running`,
`compact` (400×860), `stats`, `timeline`, `settings`.

Notes: the quota-email banner is dismissed before capture so it doesn't sit on
every hero image; `Notification.permission` reads "not asked yet" because
headless Chromium would otherwise report it as denied.
